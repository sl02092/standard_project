Codebase for the MSc disseration paper 'Distilling Structured Social Attention for Proac-tive Gaze Anticipation in Human-Robot Interaction'
This code does note represent a single holistic project, but a collection of small programs which together.


Related files are determine by the numberic pre-fix...

000_* files refer to python code used to configure datasets for use with this project.

001_* provides any/all files that I was able to upload for temporal work

002_* provides files which allow you to build 'teacher'

003_* provides files used to distill teachers knowledge to a student

004_* provides files for examining results generated by the student.


Instructions for use is provided in-file.

All required files for each step are grouped within the relevent folders.
